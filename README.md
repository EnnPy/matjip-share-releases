# 맛집 공유 (matjip-share)

친구·가족과 맛집을 지도 위에서 함께 모으고 공유하는 Android 앱입니다.
이 저장소에는 소스 코드가 없고, 설치 파일(APK)만 [Releases](https://github.com/EnnPy/matjip-share-releases/releases)로 배포합니다.

## 다운로드

**[최신 버전 다운로드](https://github.com/EnnPy/matjip-share-releases/releases/latest)**

페이지 아래 *Assets*의 `matjip-share-v<버전>.apk`를 받으세요. 로그인은 필요 없습니다.
(`.sha256` 파일은 다운로드 무결성 확인용입니다.)

## Android 설치 방법

1. 휴대폰에서 위 링크를 열고 APK를 내려받습니다.
2. 내려받은 APK를 엽니다.
3. "보안상의 이유로 이 출처의 앱 설치가 차단되었습니다"라고 나오면 **설정**으로 이동해, 사용 중인 브라우저(또는 파일 앱)에 **이 출처 허용**을 켭니다.
4. 다시 APK를 열어 **설치**를 누릅니다.
5. 설치 후에는 보안을 위해 해당 앱의 "출처 허용"을 다시 꺼도 됩니다.

요구 사항: Android 6.0 이상, **64비트(arm64-v8a) 기기**. 32비트 전용 기기와 x86 기기(에뮬레이터 포함)는 지원하지 않습니다.

## 업데이트

새 버전도 같은 방법으로 APK를 내려받아 기존 앱 위에 설치하면 데이터가 유지된 채 업데이트됩니다.
업데이트는 **같은 서명 키**로 서명된 APK만 설치할 수 있습니다. 이 저장소의 공식 릴리스는 항상 같은 키로 서명되며,
다른 경로에서 받은 APK는 업데이트로 설치되지 않거나 설치하면 안 됩니다.
